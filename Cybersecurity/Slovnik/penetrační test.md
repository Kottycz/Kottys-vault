# penetrační test

Řízený **útok na vlastní systém se svolením**, aby se našly zranitelnosti dřív než útočník.

*Příklad: firma najme pentestera, ten najde neopravený Apache Tomcat a napíše zprávu.*

---

## Podrobně

- **externí** (zvenku přes internet) × **interní** (zevnitř sítě)
- smí se testovat jen **scope** – dohodnuté IP a systémy
- dělají ho [[white_hat|white hat]] hackeři
