# IP ID (IP identifikace)

Pole v [[hlavička IP|hlavičce IP]], které **identifikuje paket** a slouží k opětovnému sestavení fragmentů.

*Příklad: u nečinného stroje se IP ID zvyšuje o 1 s každým odeslaným paketem.*

---

## Podrobně

- klíč k [[idle scan]] – sleduje se, o kolik IP ID zombie vzrostlo
- rozdíl **1** = port zavřený/filtrovaný, rozdíl **2** = otevřený
- souvisí s [[fragmentace paketů|fragmentací]]

**Souvisí:** [[idle scan]], [[hlavička IP]], [[fragmentace paketů]], [[IP spoofing]]
