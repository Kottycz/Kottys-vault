# URL

**Uniform Resource Locator** – adresa zdroje na internetu.

*Příklad: `https://tryhackme.com/room/x?id=5` = protokol + doména + cesta + parametry.*

---

## Podrobně

- části: protokol, doména, port, cesta, parametry (`?`)
- podezřelé URL se kontrolují v [[urlscan.io]] a URLhaus
- citlivé údaje do URL nepatří (uloží se do logů, skenů)

**Souvisí:** [[urlscan.io]], [[phishing]], [[DNS]]
