# segment sítě

Skupina počítačů propojených **sdíleným médiem** – fyzické připojení.

*Příklad: všechna zařízení připojená k jednomu ethernetovému switchi nebo WiFi přístupovému bodu.*

---

## Podrobně

| Pojem | Odkazuje na |
| :-- | :-- |
| **segment sítě** | **fyzické** připojení |
| [[podsíť]] | **logické** připojení |

- médiem může být ethernetový přepínač nebo WiFi přístupový bod
- v síti IP je podsíť obvykle ekvivalentem jednoho nebo více segmentů

**Souvisí:** [[podsíť]], [[switch]], [[maska podsítě]]
