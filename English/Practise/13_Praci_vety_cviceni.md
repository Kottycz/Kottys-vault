# Cvičení – Přací věty (I wish, If only)

Zápis: [[13_Praci_vety]]

## Write sentences. Use I wish or If only.

1. I / wish / Mike / not / criticise me all the time.
2. If only we / can / speak / French better.
3. I wish / our neighbours / not play / loud music all the time.
4. I / wish / we / not have / a big test on Monday.
5. If only / I / can / buy that expensive dress.

## Can you find mistakes?

1. I wish they was here now.
2. She wish her boyfriend looked like Johny Depp.
3. If only I could flew.
4. I wish I haven't got any siblings.
5. If only I not were so shy.

## Practise

1. I wish I .................... a car. (can, drive)
2. I wish we .................... go to school tomorrow. (not, have to)
3. If only I .................... a mountain bike. (have)
4. I wish they .................... nicer to me. (be)
5. If only I .................... a better cook. (be)
6. If only we .................... there more often. (can, go)
7. I wish she .................... so much salt in her soups. (not, put)
8. I wish our flat .................... on the top floor. (not, be)
9. I wish I .................... the answer to this question. (know)

## Výsledky

### Write sentences

1. I wish Mike **wouldn't criticise** me all the time.
2. If only we **could speak** French better.
3. I wish our neighbours **wouldn't play** loud music all the time.
4. I wish we **didn't have** a big test on Monday.
5. If only I **could buy** that expensive dress.

### Can you find mistakes?

1. I wish they **were** here now.
2. She **wishes** her boyfriend looked like Johny Depp.
3. If only I could **fly**.
4. I wish I **didn't have** any siblings.
5. If only I **weren't** so shy.

### Practise

1. I wish I **could drive** a car.
2. I wish we **didn't have to** go to school tomorrow.
3. If only I **had** a mountain bike.
4. I wish they **were** nicer to me.
5. If only I **were** a better cook.
6. If only we **could go** there more often.
7. I wish she **didn't put** so much salt in her soups.
8. I wish our flat **weren't** on the top floor.
9. I wish I **knew** the answer to this question.
