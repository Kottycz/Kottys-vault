# Cvičení – Modální slovesa (minulost)

Zápis: [[09_Modalni_slovesa_minulost]]

## Dejte výrazy do minulého času

1. I must do it →
2. I have to do it →
3. I needn't do it →
4. I don't have to do it →
5. I am (not) allowed to →
6. I can (not) do it →
7. I need to do it →
8. I don't need to do it →
9. I should / ought to do it →
10. I shouldn't do it →

---

## Výsledky

1. I must do it → **I had to do it**
2. I have to do it → **I had to do it**
3. I needn't do it → **I didn't have to do it** / **I needn't have done it**
4. I don't have to do it → **I didn't have to do it**
5. I am (not) allowed to → **I was (not) allowed to**
6. I can (not) do it → **I could (not) do it**
7. I need to do it → **I needed to do it**
8. I don't need to do it → **I didn't need to do it**
9. I should / ought to do it → **I should have done it**
10. I shouldn't do it → **I shouldn't have done it**
