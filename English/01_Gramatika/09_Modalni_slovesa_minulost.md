# 09 – Modální slovesa (minulost)

Modal verbs of obligation, prohibition and advice in the past

## Dejte výrazy do minulého času

| Přítomnost | Minulost |
| :-- | :-- |
| I **must** do it | I **had to** do it |
| I **have to** do it | I **had to** do it |
| I **needn't** do it | I **didn't have to** do it |
| I **don't have to** do it | I **didn't have to** do it |
| — | I **needn't have done** it |
| I **am (not) allowed to** | I **was (not) allowed to** |
| I **can (not)** do it | I **could (not)** do it |
| I **need to** do it | I **needed to** do it |
| I **don't need to** do it | I **didn't need to** do it |
| I **should / ought to** do it | I **should have done** it |
| I **shouldn't** do it | I **shouldn't have done** it |
