# 15 – Impersonal passive constructions

Neosobní trpný rod

## 1) Věty se dvěma podměty

**believe / know / think / say / expect / claim / report**

How to say it in passive?

> They expected that the hurricane would lose strength gradually.
>
> **It was expected that** the hurricane would lose strength gradually.

We use the **impersonal IT**, this passive construction with *it* is **formal English**. So, for example, we wouldn't usually use it in a conversation with friends.

## 2) Věty s jedním podmětem

> **subject + be + believed/known, etc. + to + infinitive**

> The number of extreme weather events is expected to increase.

(to talk about **present** beliefs and thoughts).

> **subject + be + believed/known, etc. + to + have + past participle**

> Alexander the Great is known to have died in Babylon.

(to talk about **past** events or situations).

## Nejčastější slovesa

**believe / know / think / say / expect / claim / report** + přítomný a minulý infinitiv

| Sloveso | Příklad |
| :-- | :-- |
| **say** | He is said to be very smart. |
| **think** | She is thought to be rich. |
| **believe** | He was believed to be innocent. |
| **consider** | The book is considered to be excellent. |
| **know** | The British are known to be very conservative. |
| **suppose** | They are supposed to return by midday. |
| **expect** | A new album is expected to come out in September. |
| **claim** | The phone is claimed to survive in extreme temperatures. |
| **allege** | The politician is alleged to have accepted a bribe. |
| **report** | Seven people were reported to have died. |
| **prove** | These chemicals are proved to cause severe health problems. |

## Cvičení

Zadání: [[15_Impersonal_passive_cviceni]]

### Solution – Rewrite the sentences using the impersonal IT construction

1. **It is claimed that** the new policy will benefit small businesses.
2. **It was said that** that medicine was effective for treating headaches.
3. **It has been reported that** the train has been delayed due to technical issues.
4. **It is believed that** climate change is accelerating.
5. **It is thought that** the new film will break box office records.

### Solution – Rewrite using subject + be + believed/known, etc.

1. The suspect **is thought to be hiding** in a remote area.
2. The virus **is believed to have spread** faster than expected.
3. The team **is believed to win** the championship.
4. The manuscript **is believed to have been written** in the 12th century.
5. The dinosaurs **are claimed to have become** extinct due to a meteorite.
6. The company **is thought to be planning** a major merger.
