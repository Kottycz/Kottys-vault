# SYST

**SYST** (System LED) – kontrolka switche, která ukazuje, jestli je **systém napájený a funguje správně**. Příklad: zelená = vše OK, oranžová = switch má napájení, ale něco nefunguje.

---

## Podrobně

| Barva | Význam |
| :-- | :-- |
| vypnuto | systém není napájen |
| **zelená** | systém pracuje normálně |
| **oranžová** | napájení je, ale systém nefunguje správně (např. selhal [[POST]]) |

Je to první kontrolka, kterou se po zapnutí dívej. Ostatní LED viz [[LED switche]].
