# IEEE

**Institute of Electrical and Electronics Engineers** – organizace vydávající technické standardy pro sítě a hardware. Stojí za Ethernetem (802.3) i Wi-Fi (802.11). Čte se "áj tripl í".

---

## Podrobně

### Důležité standardy řady 802

| Standard | Co definuje |
| :-- | :-- |
| **802.3** | Ethernet (drátové sítě) |
| **802.11** | Wi-Fi / WLAN |
| **802.1Q** | VLAN (značkování rámců) |
| **802.1X** | ověřování přístupu k síti |
| **802.2** | [[LLC]] podvrstva |
| **802.3af/at** | PoE (napájení po Ethernetu) |

### Generace Wi-Fi (802.11)

| Standard | Marketingový název | Pásmo |
| :-- | :-- | :-- |
| 802.11n | Wi-Fi 4 | 2,4 + 5 GHz |
| 802.11ac | Wi-Fi 5 | 5 GHz |
| 802.11ax | Wi-Fi 6 | 2,4 + 5 GHz |
| 802.11be | Wi-Fi 7 | + 6 GHz |

### Co ještě IEEE spravuje

Přiděluje výrobcům **[[OUI]]** – prefixy [[MAC adresa|MAC adres]], díky kterým je každá síťová karta na světě jedinečná.

### Vztah k ostatním organizacím

IEEE řeší **fyzickou a spojovou vrstvu** (jak posílat bity po drátě a rámce po síti), zatímco [[IETF]] řeší vyšší vrstvy (protokoly internetu) a [[ISO]] vydala referenční model [[OSI]].

**Souvisí:** [[ISO]], [[IETF]], [[OUI]], [[MAC adresa]], [[LLC]]
