# CAL

**Client Access License** – licence, kterou musí mít uživatel nebo zařízení, aby smělo přistupovat k Windows Serveru. Např. 30 učitelů = 30 uživatelských CAL.

---

## Podrobně

- Windows Server se licencuje **podle jader** (min. 16) + CAL
- User CAL (na osobu) nebo Device CAL (na zařízení)

**Souvisí:** [[KMS]], [[00a_Virtualizace_edice_aktivace]]
