# ADUC

**Active Directory Users and Computers** – grafická konzole pro správu uživatelů, skupin, počítačů a [[OU]] v doméně. Spouští se `dsa.msc` nebo Server Manager → Tools.

---

## Podrobně

- zakládání účtů (New → User, kopie šablony), přesun objektů mezi [[OU]]
- **View → Advanced Features** odkryje další záložky (Object, Attribute Editor) – např. vypnutí ochrany [[OU]] proti smazání
- záložka **Profile** – domovská složka a kočovný profil

**Souvisí:** [[OU]], [[AD DS]], [[04a_Navrh_OU]]
