```csharp
Console.WriteLine("Jaké máš jméno a věk");
string jmeno = Console.ReadLine();

int vek = int.Parse(Console.ReadLine());
Console.WriteLine($"Jméno: {jmeno}, Věk: {vek}");

Console.WriteLine("Napiš první číslo");
int cislo1 = int.Parse(Console.ReadLine());

Console.WriteLine("Napiš druhé číslo");
int cislo2 = int.Parse(Console.ReadLine());

int soucet = cislo1 + cislo2;
int rozdil = cislo1 - cislo2;
int nasob = cislo1 * cislo2;
int del = 0; // deklarace před if

if (cislo2 == 0)
{
    Console.WriteLine("Nelze dělit nulou");
}
else
{
    del = cislo1 / cislo2; // přiřazení do existující proměnné
}

Console.WriteLine($"Součet: {soucet}, Rozdíl: {rozdil}, Násobení: {nasob}, Dělení: {del}");
```

## Co příště zlepšit

- **`int.Parse` spadne na nečíselném vstupu** – použít `int.TryParse(Console.ReadLine(), out int cislo)` a vstup opakovat ve `while`.
- **Celočíselné dělení** – `7 / 2` vyjde 3, ne 3,5. Na desetinný výsledek přetypovat: `double vysledek = (double)cislo1 / cislo2;`.
- **Při dělení nulou se stejně vypíše `Dělení: 0`** – zavádějící. Lepší vypsat výsledky až za podmínkou, nebo místo `int del` použít `string delText`.
- `Console.ReadLine()` vrací `string?` – proto ty žluté warningy o možném `null`.
