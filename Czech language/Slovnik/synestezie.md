# synestezie

**Trop – propojení vjemů z různých smyslů do jednoho výrazu.**

> *„hořký zápach"* (chuť + čich), *„teplé barvy"* (hmat + zrak), *„křiklavá barva"* (sluch + zrak)

---

## Podrobně

### Princip

Z řečtiny *syn* (spolu) + *aisthésis* (vnímání). Vjem jednoho smyslu se popíše slovem, které patří jinému smyslu. Vzniká neobvyklé, smyslově bohaté spojení.

### Kombinace smyslů

| Příklad | Spojené smysly |
| :-- | :-- |
| *hořký zápach* | chuť → čich |
| *teplé barvy* | hmat → zrak |
| *sametový hlas* | hmat → sluch |
| *křiklavá barva* | sluch → zrak |
| *sladká hudba* | chuť → sluch |
| *stříbrné ticho* | zrak → sluch |

### Kde je typická

- **[[symbolismus]] a [[impresionismus]]** – básníci moderny chtěli zachytit **celkový dojem** a náladu, ne přesný popis; smyslové vjemy se jim prolínaly. Verlaine – „hudba slov".
- **romantismus** – atmosférické popisy přírody
- běžný jazyk – spousta synestezií zevšedněla (*teplé barvy, ostrý hlas*)

**Souvisí:** [[impresionismus]], [[symbolismus]], [[metafora]], [[epiteton]], [[básnické prostředky]]
