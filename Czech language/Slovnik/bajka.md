# bajka

**Krátký epický příběh, ve kterém zvířata (nebo věci) jednají jako lidé, s ponaučením na konci.**

> Ezop, La Fontaine – *Liška a čáp*: chovej se k lidem tak, jak chceš, aby se chovali k tobě

---

## Podrobně

### Znaky

- **zvířata s lidskými vlastnostmi** ([[personifikace]]) – liška = chytrost, lev = síla, osel = hloupost
- **krátký, jednoduchý děj**
- **ponaučení (morálka)** – na konci výslovně, nebo vyplyne z děje
- **[[alegorie]] (jinotaj)** – zvířata ve skutečnosti představují lidi
- próza i verš

### Typické zvířecí postavy

| Zvíře | Vlastnost |
| :-- | :-- |
| liška | lstivost, chytrost |
| vlk | krutost, hamižnost |
| lev | síla, moc, panovník |
| osel | hloupost |
| mravenec | pracovitost |
| páv | pýcha |

### Autoři

| Autor | Období |
| :-- | :-- |
| **Ezop** | antika, Řecko – zakladatel žánru |
| **Jean de La Fontaine** | [[klasicismus]], Francie – *Bajky* (1660–1690), satirický obraz společnosti, politický podtext |
| **I. A. Krylov** | Rusko |
| *Bajka o lišce a džbánu* | první česká bajka (Hradecký rukopis, 14. stol.) |
| Smil Flaška, *Nová rada* | zvířata radí králi |
| K. Čapek, I. Olbracht, J. Žáček | 20. století |

### V klasicismu

Bajka patřila mezi **nízké žánry** (vedle komedie, frašky, satiry).
