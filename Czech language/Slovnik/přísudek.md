# přísudek

Základní větný člen (Př), ptáme se: co dělá podmět? Podtrháváme vlnovkou. Př. Katka si češe vlasy.

Druhy: jmenný se sponou, jmenný beze spony, jmenný se sponou složený, citoslovečný, slovesný jednoduchý, slovesný složený. Spona = být, bývat, stát se, stávat se. Fázová slovesa: začít, přestat, zůstat. Způsobová: moci, smět, muset, mít, chtít.
