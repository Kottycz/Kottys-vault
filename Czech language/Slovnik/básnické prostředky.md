# básnické prostředky

**Jazykové prostředky, kterými autor dělá text obrazným, zvukově zajímavým a citově působivým. Dělí se na tropy, figury a zvukové/jazykové prostředky.**

> *„o lásce šeptal tichý mech"* – [[personifikace]] (trop)

---

## Podrobně

### Tropy

**Přenášení významu** slova na jinou věc – na základě podobnosti nebo souvislosti. Z řečtiny *tropos* = „obrat". Mění **význam**.

| Trop | Na čem stojí | Příklad |
| :-- | :-- | :-- |
| [[metafora]] | vnější podobnost | *hlava rodiny* |
| [[personifikace]] | lidské vlastnosti neživému | *přichází jaro* |
| [[přirovnání]] | srovnání přes „jako" | *starý jako Metuzalém* |
| [[alegorie]] | celé dílo = metafora | *Farma zvířat* |
| [[metonymie]] | vnitřní souvislost | *poslouchat Beethovena* |
| [[synekdocha]] | část × celek | *ani noha* |
| [[symbol]] | ustálený znak | *černá kočka* |
| [[oxymóron]] | spojení protikladů | *mrtvé milenky* |
| [[hyperbola]] | nadsázka | *říkal jsem ti to stokrát* |
| [[epiteton]] | básnický přívlastek | *stříbrné ticho* |
| [[ironie]] | opak míněného | *to se ti povedlo* |
| [[sarkasmus]] | kousavá ironie | – |
| [[synestezie]] | míchání smyslů | *hořký zápach* |

### Figury

**Práce s uspořádáním slov** – opakování, vynechávání, přehazování. Z latiny *figura* = „tvar". Mění **stavbu**, ne význam slov.

| Figura | Princip |
| :-- | :-- |
| [[anafora]] | opakování na začátku veršů |
| [[epifora]] | opakování na konci veršů |
| [[epizeuxis]] | opakování hned za sebou |
| [[epanastrofa]] | konec verše → začátek dalšího |
| [[aliterace]] | stejná hláska na začátku slov |
| [[apostrofa]] | oslovení nepřítomného |
| [[řečnická otázka]] | otázka bez odpovědi |
| [[inverze]] | přehozený slovosled |
| [[elipsa]] | vynechání domyslitelného |
| [[aposiopeze]] | nedokončená výpověď |
| [[asyndeton]] | bez spojek |
| [[polysyndeton]] | nadbytek spojek |
| [[paronomázie]] | podobně znějící slova |
| [[litotes]] | zápor opaku |
| [[pleonasmus]] | nadbytečné spojení |
| [[tautologie]] | totéž dvěma synonymy |

### Jazykové a zvukové prostředky

Nejsou tropy ani figury:

- [[eufemismus]] / [[dysfemismus]] – zjemnění / zhrubění
- [[gradace]] – stupňování
- [[eufonie]] / [[kakofonie]] – libozvučnost / nelibozvučnost
- [[onomatopoie]] – zvukomalba

### Pomůcka na rozlišení

- **trop** = slovo znamená **něco jiného**, než normálně (přenesený význam)
- **figura** = slova znamenají to, co normálně, ale jsou **neobvykle uspořádaná**
