# pleonasmus

**Nadbytečné spojení slov, z nichž jedno už obsahuje význam druhého.**

> *„modrý blankyt"* – blankyt je sám o sobě modrý

---

## Podrobně

### Princip

Z řečtiny *pleonasmos* = „nadbytek". Vedle sebe stojí výrazy, které říkají **totéž** – typicky přívlastek, který jen opakuje vlastnost podstatného jména.

### Dvojí tvář

- **v umělecké literatuře** – záměrný prostředek: zdůrazní vlastnost, zpomalí, dodá básnivost (*„modrý blankyt"*, *„bílý sníh"*)
- **v běžném a odborném textu** – **stylistická chyba** (zbytečné opakování)

### Typické chybné pleonasmy

| Pleonasmus | Proč je nadbytečný |
| :-- | :-- |
| *vrátit se zpět* | vrátit se = jít zpět |
| *vzájemná spolupráce* | spolupráce je vždy vzájemná |
| *stoupat nahoru* | stoupat = jít nahoru |
| *předem připravit* | připravit = předem |
| *mladý novorozenec* | novorozenec je vždy mladý |

### Rozdíl od tautologie

- **pleonasmus** – jedno slovo **už obsahuje** význam druhého (*modrý blankyt*)
- [[tautologie]] – dvě **synonyma** vedle sebe (*neveselý, truchlivý*)
