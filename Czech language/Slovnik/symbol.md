# symbol

**Obecně známý znak (věc, barva, zvíře, jev), který zastupuje určitou myšlenku, vlastnost nebo situaci.**

> *„Přeběhla mi černá kočka přes cestu."* = smůla, neštěstí

---

## Podrobně

### Princip

Z řečtiny *symbolon* = „poznávací znamení". Konkrétní věc odkazuje k něčemu **abstraktnímu**. Na rozdíl od [[metafora|metafory]] je význam symbolu **ustálený** a sdílený v kultuře – většina lidí mu rozumí stejně.

### Běžné symboly

| Symbol | Význam |
| :-- | :-- |
| černá kočka | smůla |
| holubice | mír |
| kříž | křesťanství, utrpení |
| srdce | láska |
| lilie, bílá barva | čistota, nevinnost |
| Slunce | život |
| noc, tma | smrt, tajemství |
| lebka | smrt, pomíjivost |

### V literatuře

- **romantismus** – příroda jako symbol duševního stavu (Mácha, *Máj*)
- **realismus** – Čechovův *Višňový sad* jako symbol starého Ruska
- **moderna** – [[symbolismus]] celý stojí na symbolech: nepopisuje skutečnost přímo, ale naznačuje ji (Slunce = symbol života)

### Symbol vs. alegorie

- **symbol** – jeden znak s ustáleným významem (holubice = mír)
- [[alegorie]] – celý příběh s přeneseným významem (bajka)

**Souvisí:** [[symbolismus]], [[alegorie]], [[metafora]], [[básnické prostředky]]
