# eufemismus

**Zjemňující výraz – mírnější, šetrnější pojmenování nepříjemné, tabuizované nebo drsné skutečnosti.**

> *„navždy nás opustil"* místo *„zemřel"*

---

## Podrobně

### Princip

Z řečtiny *eu* (dobře) + *femi* (mluvím) = „mluvit hezky". Místo přímého, tvrdého slova se použije opis nebo jemnější výraz.

### K čemu slouží

- **ohleduplnost** – smrt, nemoc, stáří
- **zdvořilost, stud** – tělesné potřeby, sex
- **zmírnění nepříjemné zprávy** – politika, byznys
- **pověra** – dřív se nevyslovovala jména nebezpečných zvířat nebo ďábla

### Příklady

| Přímo | Eufemisticky |
| :-- | :-- |
| zemřel | *navždy nás opustil, odešel, zesnul* |
| starý | *v pokročilém věku, senior* |
| lže | *nemluví tak úplně pravdu* |
| záchod | *toaleta, WC, kam i císař pán chodí pěšky* |
| propustit | *optimalizovat stavy, uvolnit* |
| válka | *speciální vojenská operace* |

### Opak

[[dysfemismus]] – naopak **hrubší, drsnější** výraz (*chcípl* místo *zemřel*).

### Souvislost

Blízko má k [[litotes]] (*„není to zrovna nejchytřejší"*) – obojí zjemňuje.
