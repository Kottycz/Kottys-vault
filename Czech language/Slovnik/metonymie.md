# metonymie

**Trop – přenesení pojmenování na základě vnitřní (věcné) souvislosti mezi dvěma věcmi.**

> *„Posloucháme Beethovena."* = posloucháme jeho hudbu (autor → dílo)

---

## Podrobně

### Princip

Z řečtiny *metónymia* = „přejmenování". Věci si **nejsou podobné** (to by byla [[metafora]]), ale **spolu souvisejí** – jedna se pojmenuje podle druhé.

### Typy souvislosti

| Souvislost | Příklad | Význam |
| :-- | :-- | :-- |
| autor → dílo | *mít Picassa*, *číst Máchu* | obraz, knihu |
| obal → obsah | *vypil celou láhev* | tekutinu v láhvi |
| místo → lidé | *celá škola se smála* | žáci a učitelé |
| místo → instituce | *Hrad oznámil…* | prezident a jeho kancelář |
| materiál → výrobek | *bronz na olympiádě* | bronzová medaile |
| příčina → následek | *má to na svědomí alkohol* | opilost |

### Metonymie vs. metafora vs. synekdocha

| Trop | Základ přenesení | Příklad |
| :-- | :-- | :-- |
| [[metafora]] | **podobnost** | *noha stolu* |
| **metonymie** | **souvislost** | *číst Nerudu* |
| [[synekdocha]] | **část × celek** | *pod jednou střechou* |

Synekdocha se někdy považuje za zvláštní druh metonymie.

### V jazyce

Stejně jako metafora rozšiřuje slovní zásobu – viz [[lexikologie]] (*mít Picassa*).
